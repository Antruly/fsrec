# fsrec 使用说明

fsrec 是一款 **数据恢复工具**：通过 Windows 原始磁盘读取接口解析 **NTFS / FAT / exFAT** 文件系统，
重建目录树，帮助你在硬盘被**误格式化、分区被覆盖或文件被删除**后，浏览并恢复文件与目录结构。

版本：**v1.0.9**（64 位 Windows）

---

## 一、这是什么 / 能做什么

| 能力 | 说明 |
|------|------|
| 只读扫描 | 解析物理磁盘上存留的 NTFS `$MFT`（主文件表）或 FAT/exFAT 目录项，定位文件与目录，**不写入源盘** |
| 分区级恢复 | 一个物理磁盘上可能有多个分区（NTFS / FAT / exFAT），逐个扫描并分别列出 |
| 浏览与搜索 | 按目录树浏览、按文件名搜索 |
| 选择性恢复 | 勾选文件/目录，按原目录结构恢复到**另一块磁盘** |
| 实时进度 | Web 界面实时显示总体进度、当前文件、每文件进度，可**暂停 / 继续 / 停止** |
| 安全锁定 | 自动锁定源磁盘与系统盘，防止误选覆盖 |

## 二、系统要求

- Windows 10 / 11（64 位）
- 需要**管理员权限**（程序启动时会触发 UAC 提权）
- **Microsoft Visual C++ 2015–2022 x64 运行库**：安装包已内置，
  首次启动时若检测到缺失会自动静默安装（Win10/11 通常已自带）

## 三、安装与启动

1. 运行安装包 `fsrec-setup-1.0.0.exe`，按向导完成安装（界面为中文）。
   安装过程中会弹出「请勿安装到需要恢复数据的磁盘」安全提示，需勾选确认后才能继续。
2. 从开始菜单或桌面快捷方式启动 **fsrec**。
3. 首次启动会弹出 **UAC 用户账户控制**，请点「是」允许提权（原始磁盘读取必须）。
4. 程序启动后会自动打开默认浏览器并进入 `http://localhost:8080`。
   - 若浏览器未自动打开，请手动访问 `http://localhost:8080`。
   - 关闭本软件：在浏览器界面停止所有任务后，可在开始菜单点「停止 fsrec」，
     或在任务栏/任务管理器结束 `recovery_server.exe`。

> 数据目录：扫描结果缓存于安装目录 `data\` 下（`scan_disk<N>[_v<K>].json`），
> 下次启动会自动重新加载，无需重新扫描。

## 四、操作流程

### 第 1 步 · 选择物理磁盘并扫描

1. 在「选择物理磁盘并扫描」卡片中，点击要恢复的物理磁盘（**磁盘 0 是系统盘，已被禁用**）。
2. 勾选「我已核对所选磁盘…并明白本次为只读扫描」确认框。
3. 点击 **「🔍 只读扫描定位」**。程序会只读遍历整盘、定位各分区的文件系统（`$MFT` / FAT / exFAT），约 3–10 分钟。
4. 扫描完成后，下方「已保存的扫描」会列出每个发现的分区。

### 第 2 步 · 加载扫描结果

- 在「已保存的扫描」中，点击某个分区的 **「加载此扫描」**。
- 界面会显示该分区的「扫描概览」：文件总数、目录数、已删除文件数、现存/已删除总量，以及最大的文件列表。

### 第 3 步 · 浏览并勾选要恢复的文件

- 在「浏览并勾选」区域展开目录树，用复选框勾选要恢复的文件或整个目录。
- 可用「搜索文件名」「全选顶层」「清空勾选」辅助操作。
- 标注说明：
  - 红色「**已删除**」：该文件在 `$MFT` 中标记为已删除。
  - 灰色「**不可恢复**」：已删除且数据区无法定位，恢复大概率失败。

### 第 4 步 · 选择输出目录并恢复

1. 点击 **「📂 浏览」** 打开目录选择器，选择一块**与源盘不同的磁盘**上的目录
   （源盘盘符会被自动禁用，不可选）。
2. 界面会实时显示「预计数据量」与「目标盘可用空间」；**空间不足时会红色警告**。
3. 点击 **「⬇️ 开始恢复」**，再次确认后开始。
4. 恢复过程中可 **暂停 / 继续 / 停止**；实时显示当前正在恢复的文件及每文件进度。
5. 完成后会显示成功/失败数量。

## 五、注意事项

- **源盘全程只读**：程序通过 `GENERIC_READ` 只读打开源盘，绝不写入源盘。
- **严禁选择磁盘 0 / 系统盘**作为扫描对象。
- **输出目录必须位于另一块磁盘**：恢复时若选择源盘或系统盘会被拦截，防止覆盖源数据。
- **勿在生产机上随意测试**：请先在可丢弃的磁盘或镜像上验证流程。
- **已删除文件不一定能恢复**：数据区可能已被新数据覆写；「不可恢复」项已明确标注。
- **同名文件不覆盖**：目标已存在同名文件时，自动追加 `_1`、`_2`… 后缀。
- **不要向源盘写入任何新数据**：误删除/误格式化后，应立即停止使用该盘，最大程度保留可恢复数据。

## 六、常见问题

**Q：启动报错「不是管理员权限 / 未提权」？**
右键程序选择「以管理员身份运行」，或确认 UAC 弹窗点了「是」。

**Q：报错缺少 `VCRUNTIME140.dll`？**
安装包已内置 VC++ 运行库，首次启动会自动检测并静默安装（需在 UAC 提示中允许）。
若仍报错，请手动安装 [Microsoft Visual C++ 2015–2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

**Q：扫描列表里看不到某块磁盘？**
确认磁盘已正常连接并被系统识别；磁盘 0（系统盘）被有意禁用。

**Q：目标盘空间不足？**
界面会红色警告，请换一块空间足够的磁盘。

**Q：某些文件显示「不可恢复」？**
该已删除文件的数据区已无法定位，通常因为已被覆写。

**Q：端口 8080 被占用？**
命令行启动时可指定端口：`recovery_server.exe --port 8090`（然后访问 `http://localhost:8090`）。
不想自动打开浏览器可加 `--no-browser`。
